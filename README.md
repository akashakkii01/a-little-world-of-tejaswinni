# A Little World of Tejaswinni ♡

A tiny, dreamy, interactive website made as a thoughtful surprise.

## Features
- Soft pastel design with floating petals and a little bear illustration
- Personal notes for cloudy days, quiet nights, and gentle reminders
- Clickable flowers with hidden messages
- Interactive gift box and a final surprise
- Responsive layout for phones, tablets, and desktops
- No login, framework, build step, or external JavaScript dependencies

## Run locally
Open `index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
Import this repository into Vercel. Use the project root as the root directory and leave the framework preset as **Other**. No build command or output directory is required; this is a static website.
